Before you launch a helper agent, run `{{command}} trace start <helper> --type sub-agent{{#trace_parent}} --parent {{trace_parent}}{{/trace_parent}}` and put the id it prints in the helper's brief: "Your parent span is `<id>`: start any span of your own with `--parent <id>`." When the helper returns, run `{{command}} trace stop <id>` (add `--status error` if it failed), chained with your next command.

# Feature: 20260101000003-help

## Overview

Make `python3 -m todo` explain itself: a usage summary when run with no
arguments, and a `--version` flag. New users currently get no output at all
and no way to tell which version they are running.

## Requirements

- [ ] **Usage with no arguments**
  Running `todo` with no arguments must print a short usage summary to stdout
  and exit with status 0.

- [ ] **Version flag**
  `todo --version` must print `todo <version>`, using the version in
  `todo/__init__.py`, and exit with status 0.

- [ ] **Describe the program in help**
  `todo --help` must include a one-line description of what the program does.

## Constraints

- Standard library only.
- The version must be read from `todo.__version__`, never duplicated.

## Acceptance Criteria

- [ ] **No arguments**
  `python3 -m todo` exits 0 and its stdout contains `usage:`.

- [ ] **Version**
  `python3 -m todo --version` prints `todo 0.1.0`.

- [ ] **Description**
  `python3 -m todo --help` contains the program description.

## Technical Approach

- Use argparse's built-in `version` action and the parser's `description`.

## Success Metrics

- Every acceptance criterion is covered by a test that passes.

## Non-Goals

- Help for individual subcommands.
- Man pages or shell completion.

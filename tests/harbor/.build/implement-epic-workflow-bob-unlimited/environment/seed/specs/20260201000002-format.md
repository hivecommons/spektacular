# Feature: 20260201000002-format

## Overview

Render a todo list as the lines the `list` command will print, in one place,
so the commands spec and any later output share the same layout.

## Requirements

- [ ] **One line per todo**
  `todo.format.format_todos(todos)` must return a list of strings, one per
  todo in ascending `id` order, each `<id>. [ ] <title>`, or `<id>. [x]
  <title>` when the todo is done.

- [ ] **An empty list says so**
  `format_todos([])` must return `["No todos."]`.

## Constraints

- Standard library only; Python 3.12.
- Only `todo/format.py` and new test files under `tests/` change.

## Acceptance Criteria

- [ ] **Layout**
  `format_todos([{"id": 2, "title": "b", "done": True}, {"id": 1, "title":
  "a", "done": False}])` returns `["1. [ ] a", "2. [x] b"]`.

- [ ] **Empty**
  `format_todos([])` returns `["No todos."]`.

## Technical Approach

- A pure function with no I/O.
- Unit tests use `unittest` in `tests/test_format.py`.

## Success Metrics

- `python3 -m unittest discover -s tests` passes.

## Non-Goals

- Colour or terminal-width handling.

# Feature: 20260201000004-export

## Overview

Let users copy their list into notes or issues: `todo export` prints the
todo list as a Markdown checklist.

## Requirements

- [ ] **Markdown checklist**
  `todo.export.to_markdown(todos)` must return one line per todo in ascending
  `id` order, `- [ ] <title>`, or `- [x] <title>` when done, each ending in a
  newline. An empty list gives the empty string.

- [ ] **Export command**
  `todo export` must write `to_markdown` of the stored todos to stdout
  unchanged, adding nothing before or after it.

## Constraints

- Read todos only through `todo.storage.load()`.
- Standard library only. Only `todo/export.py`, an `export` subcommand in
  `todo/cli.py`, and new test files under `tests/` change.

## Acceptance Criteria

- [ ] **Checklist**
  With todos `buy milk` (done) and `walk dog` (not done), `todo export`
  prints `- [x] buy milk` and `- [ ] walk dog` on two lines, in that order.

- [ ] **Empty**
  `todo export` on an empty list prints nothing.

## Technical Approach

- A pure `to_markdown` in `todo/export.py`, wired to an `export` subparser.
- Tests use `unittest` in `tests/test_export.py`.

## Success Metrics

- `python3 -m unittest discover -s tests` passes.

## Non-Goals

- Formats other than Markdown, or writing to a file.

# Feature: 20260201000003-commands

## Overview

Give `python3 -m todo` its first commands, `add`, `list` and `done`, built on
the storage module and the list format from the two earlier specs, with help
for each command and usage in the README.

## Requirements

- [ ] **Add a todo**
  `todo add <title>` must store a new, not-done todo whose id is one more
  than the highest existing id (1 for an empty list), and print
  `Added <id>`.

- [ ] **List todos**
  `todo list` must print each line of `todo.format.format_todos` for the
  stored todos.

- [ ] **Complete a todo**
  `todo done <id>` must mark that todo done and print `Done <id>`.

- [ ] **Reject an unknown id**
  `todo done <id>` for an id that does not exist must print `No todo <id>`
  to stderr and exit with status 1.

- [ ] **Describe each command in help**
  `todo --help` must list `add`, `list` and `done`, each with a one-line
  description.

- [ ] **Document usage in the README**
  The README must gain a `## Usage` section showing each command with an
  example.

## Constraints

- Read and write todos only through `todo.storage.load()` and
  `todo.storage.save()`, and render the list only through
  `todo.format.format_todos`.
- Standard library only. Only `todo/cli.py`, `README.md` and new test files
  under `tests/` change.

## Acceptance Criteria

- [ ] **Add then list**
  On an empty list, `todo add "buy milk"` prints `Added 1`, and `todo list`
  then prints `1. [ ] buy milk`.

- [ ] **Done**
  `todo done 1` prints `Done 1`, and `todo list` then prints
  `1. [x] buy milk`.

- [ ] **Unknown id**
  `todo done 99` on a list without id 99 exits 1 and writes `No todo 99` to
  stderr.

- [ ] **Help**
  `todo --help` exits 0 and names `add`, `list` and `done`.

- [ ] **README**
  `README.md` has a `## Usage` section naming `todo add`, `todo list` and
  `todo done`.

## Technical Approach

- `argparse` subparsers in `todo/cli.py`, each with a `help` string.
- Tests use `unittest` in `tests/test_commands.py`, with `TODO_FILE` pointed
  at a temporary file.

## Success Metrics

- `python3 -m unittest discover -s tests` passes.

## Non-Goals

- Deleting or editing todos.

# Task

A single unit of work in a plan, listed under a milestone and carried out in exactly one registered repo by one kind of executor, an agent or a person. It is identified by a permanent id and declares the tasks it depends on. A task sits below a milestone and is never a synonym for a step or a stage. Plans written before tasks called this unit a phase (`Phase N.M`).
